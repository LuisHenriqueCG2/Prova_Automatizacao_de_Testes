### Clonando o projeto:  
- git clone https://github.com/LuisHenriqueCG2/Prova_Automatizacao_de_Testes  

### Linguagem e Framework utilizado:  
- C# com .NET Framework 10.0  
- xUnity para testes automatizados

### Pacotes necessários:  
- Selenium

### Descrição:  

A automação consiste em realizar acessar a ferramente interna da Inside Sistemas - Inside Backoffice e realizar o login automaticamente na plataforma.  
É necéssário realizar a configuração do seu e-mail e senha ao rodar o teste.
